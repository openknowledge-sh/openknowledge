# Example research notes demo

This knowledge base asks how a citation-review workflow should preserve
evidence for the next person or AI agent.

## Research

- [Research question](research/question.md)
- [Citation workflow findings](research/citation-workflow.md)

## Useful commands

```sh
okn search Wiki "what evidence supports the citation workflow?"
okn validate Wiki
okn view Wiki
```

The findings summarize public English Wikipedia pages. Check the linked source
pages before you treat a summary as current policy.

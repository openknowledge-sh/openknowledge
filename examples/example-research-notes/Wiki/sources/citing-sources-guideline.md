# Wikipedia Citing sources guideline

## Source record

- Publisher: English Wikipedia community
- Page type: Content guideline
- Reviewed: 2026-08-08
- Resource: [Wikipedia:Citing sources](https://en.wikipedia.org/wiki/Wikipedia:Citing_sources)

## Relevant points

- Citations identify the source used for article content.
- Citation details should make the source easy to identify.
- Inline citations connect a claim to its supporting source.
- A citation should include a precise locator when that detail helps readers.

## Use in this demo

The synthesis uses this guideline for the evidence-locator finding.

## Limits

This note does not prescribe a single citation style. Use the external
guideline for current formats, placement rules, and exceptions.

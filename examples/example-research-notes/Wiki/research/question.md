# Evidence-preserving citation review

## Question

What evidence must a citation-review workflow preserve so another person can
check a finding without repeating the initial source search?

## Scope

- Review public English Wikipedia policy and help pages.
- Focus on verifiability, source selection, and citation records.
- Exclude editor interviews, usage data, and software comparisons.

## Completion criteria

- Keep one source note for each external page.
- Link each source-dependent finding to a source note.
- State limits and open questions in the synthesis.

# Research notes use case

## Scope and mode

- Primary target: `use-cases/research-notes/index.html`
- Mode: Persuade through a Read-oriented conversion guide.

## Audience and job

Developers and product teams use agents to investigate project questions. The
page must show how they preserve raw sources, citations, synthesis, limits, and
open questions as durable context.

## Action and proof

The primary action starts Getting Started. Proof comes from exact setup and
rule commands, OKF source metadata, local source-preserving search, explicit
review boundaries, and four honest screenshot briefs.

## Chosen direction

Inherit the established use-case article system. Move from disposable summaries
to a small source-and-synthesis structure, a traceable research note, an
evidence-first agent loop, local retrieval, and uncertainty review.

## Constraints

Use only shipped behavior. Label the research structure and sample findings as
illustrative. Do not invent customer proof, screenshots, automatic source
verification, or claims that validation certifies research quality.
Apply ASD-STE100 to visible copy. Explain each technical term for readers
without software experience.

## Unresolved decisions

Real screenshots can replace the briefs after a public demo research task is
captured. The decision-record route remains outside this page.

# Use cases index

## Scope and mode

- Primary target: `use-cases/index.html`
- Visitor mode: Read
- This page is the directory for finished use-case guides.

## Audience and job

Software teams need to choose the project knowledge that they want to keep.
The reader must identify one recurring context problem and open the matching guide.

## Action and proof

The primary action is to open Project documentation, Changelogs, or Research notes.
Each entry names the knowledge it keeps and links to a finished guide.
The final action links to Getting started.

## Direction

Use an annotated field-guide index with three full-width entries. Preserve the
light-blue field, deep-blue type, file-path labels, quiet rules, and direct copy.
Do not use a generic card grid or invent customer proof.

## Memorable moment

The three guide entries read like durable project files. Each entry expands
slightly on hover and exposes one direct reading action.

## Constraints

Use ASD-STE100 language. Keep claims consistent with the finished guides and
repository documentation. Support keyboard navigation and a 320-pixel viewport.

## Unresolved decisions

Add decision records as a fourth guide only after that page exists.

05/ how it works

From changing sources to trusted agent context.

  1. connect Connect what you already have.

    Point Open Knowledge at your existing Markdown repository. Keep your files, Git history, and workflow.

  2. detect Detect what is breaking.

    Continuously check for stale references, conflicts, missing answers, and unsupported claims.

  3. repair + test Repair and test.

    Collect evidence, propose a focused diff, and compare agent answers before and after the change.

  4. serve last green Serve the last green version.

    Publish approved knowledge as a versioned release and keep failed changes away from agents.

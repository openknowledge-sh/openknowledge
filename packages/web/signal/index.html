01 / THE CONTEXT PROBLEM

A convincing answer.
A broken assumption.

Search can find the right topic in the wrong version. More context does not fix stale context. Engineers still have to trace the source, reconcile the mismatch, and explain it all over again.

01

The docs drift.

An API changes. A runbook doesn’t. The next person—or agent—follows instructions that no longer match the system.

02

The reasoning disappears.

The decision is in a conversation. The implementation is in Git. Without a durable record, every new task starts with archaeology.

03

The mistake spreads.

Retrieval makes a document easy to reuse. Without checks and evidence, it also makes an outdated assumption easy to repeat.

02 / CLOSE THE LOOP

LESS GUESSWORK

Find the knowledge
that needs attention.

Audits surface concrete risks with affected files and evidence. Configure source baselines to detect changes, and typed claims to catch conflicting facts.

ILLUSTRATIVE AUDIT
$ okn audit Wiki --fail-on high

! Source changed
  docs/auth.md → api/auth.yaml

! Conflicting typed claims
  token_expiry: 24h / 12h

Next: inspect evidence and review.

ONE MAINTAINED FOUNDATION

AFTER SETUP AND OUTPUT CONFIGURATION

$ okn publish Wiki --plan

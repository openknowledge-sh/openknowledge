From Markdown to shared context.

Five common paths through the CLI, from setup to publishing.

Create a knowledge base

Start the guided setup interview, or let the CLI launch a selected agent runtime.

okn setup okn setup --agent codex

Build from another source

Print an agent task grounded in a repository, folder, or website.

okn setup Wiki --prompt --from https://github.com/openknowledge-sh/openknowledge okn setup Wiki --prompt --from https://openknowledge.sh/wiki/ --depth 2

Connect and retrieve

Give the bundle a stable name, then search it or browse it locally.

okn connect Wiki --as project okn search project "validation workflow" okn view project

Validate before use

Catch structure errors and review link warnings before agents or publishing depend on the knowledge base.

okn validate Wiki okn list --depth 2 Wiki okn ast Wiki

Publish or integrate

After review, set [publish] enabled = true to ship HTML. Export portable JSON or a complete source archive separately.

okn export html --out ./project-site Wiki okn export json Wiki okn export tar --out ./project-wiki.tar.gz Wiki
